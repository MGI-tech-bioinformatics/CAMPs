# Output specification
# CAMPs output files

CAMPs offers the following output files:

- **Input.bed:** The input regions. If the raw input is genename, the genes' exon/cds regions' coordinate 
would be extracted from the database.

- **amplicon_region.bed:** The amplicons bed file.

-**cover_target_region.bed:** The amplicon covered regions bed file.

-**missing_target_region:** The missing target regions which is uncovered by amplicons.

- **Output.xlsx:** The primers' sequence and coordinates result.

- **<order_num>.html:** The CAMPs designer report. Including a summary about primer design, amplicons GC distribution
, amplicons size distribution, homology target region, abandon target region and failed target region.
